# Tool Calling 검증 프롬프트 (T-266 S-1·S-2·S-3, PLAN_v61)

## 전제

* 서버 경로 S-3 완료 → 1~11번 서버 경로로 검증 가능 (gemma4-12b 실데몬 E2E 통과).
  네이티브는 FC 지원 모델 보유 시에만 칩 표시.
* 권한을 설정에서 바꿔가며 테스트 (사용 안 함 / 매번 묻기 / 모두 허용).
* DebugPanel `[도구]` 로그 3종 확인: `호출 감지` → `승인 요청` → `실행 반영`.

## 기본 (도구 호출 자체)

1. `지금 몇 시야?` — `get_time` 호출 기대
2. `오늘 날짜 알려줘` — 날짜 포함 응답인지
3. `(1+2)*3 계산해줘` — `calculate` 호출, `9` 응답인지
4. `1234 * 5678은 얼마야?` — 큰 수 계산 (`7006652`)
5. `100을 7로 나누면?` — 소수 응답

## 권한 게이트

6. 매번 묻기 + `지금 몇 시야?` → 허용 → 시간 응답
7. 매번 묻기 + `지금 몇 시야?` → 거부 → 거부 문구 포함 응답 + 칩 `거부됨`
8. 사용 안 함 + `지금 몇 시야?` → 도구 호출 없이 모델 자체 답변 (칩 없음)

## 오류·복합

9. `0 나누기 0은?` — 계산 실패 문구 + 칩 `실패` (E-MAC-ENG-0004 로그)
10. `2의 10제곱은?` — `^` 미지원이라 실패 처리되는지 (파서 범위 확인)
11. `지금 시각 기준으로 100분 후는 몇 시야?` — 시간+계산 2연속 호출, 칩 2개 + 푸터 `🔧2`

## Thinking (thinking 지원 모델 보유 시)

12. `365*24를 단계별로 생각해서 풀어줘` — 생각 접기 블록 펼침 확인

## Qwen3-4B 주의 (실측)

* `describe`는 Function Call NO지만 서버 경로에서 tool_calls 정상 방출 (+`<think>` 추론).
* 기본 config의 `audio_backend`·`vision_backend`가 있으면 대화 생성 실패.
  모델별 오버라이드로 안 없어짐 → 외부 데몬으로 최소 config 사용:
  `litert-lm serve --host 127.0.0.1 --port 9379 --config <audio·vision 없는 config>`
  (앱은 외부 데몬으로 연결됨). 앱 관리 데몬으로는 gemma 계열 사용.
