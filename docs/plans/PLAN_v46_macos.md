# PLAN v46 — 사이드바 탭 분리+상단 고정 (macOS)

## 1. 목표

* T-230: 사이드바 상단 [채팅 | 모델] 탭. 채팅 무한 증식에도 모델·벤치마크 접근 보장.
* T-231: 환경+탭 상단 고정. 목록 스크롤과 무관하게 정보·탭 전환 상시 노출.
* 규칙 3종 (중구난방 해소): ① 엔진 영역은 입력창 route 추종 (CLI=데몬 버튼, 네이티브=네이티브 버튼).
  ② 모델 단일 진실 (selectedModelID→chat.model·config 동기, 현행 유지).
  ③ 버튼은 아이콘+짧은 한 줄 라벨, 대상·상태는 값 행 표시.
* 모델 섹션 채팅식 개편 (T-231 후속): 헤더(모델+건수)+관리 버튼+선택행+호버 메뉴. T-232 모델 관리 창 후속.

## 2. 현상 근거

* 단일 List에 환경→채팅(무제한)→벤치마크(무제한)→모델 (`SidebarView.swift:9-64`).
* 채팅·기록이 늘면 모델 섹션이 하단으로 밀림.

## 3. 변경

* `SidebarView.swift`만: 상단 segmented 탭 + `@AppStorage("sidebarTab")` 영속.
  채팅 탭=SessionListView, 모델 탭=BenchmarkListView+모델 Section. 환경은 항상 고정.
* 본문 로직 불변 (이동만). 벤치마크 독립 탭 없음 (모델 탭에 포함).
* T-231: `sidebar`를 VStack 2층으로 (고정층=환경 카드+탭, 스크롤층=List 활성 탭만).
* 회귀 1건: 탭 기본값 채팅+키 영속.

## 4. 검증

* unit + lint 신규 0 + build 전체 (상시 2번). 눈확인: 전환·재실행 유지·긴 목록 접근.
* PERF/CACHE 영향 없음.
