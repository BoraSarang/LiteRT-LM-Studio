# PLAN v5 — 중앙 카드 바깥 여백 (macOS, T-098)

> 요청: 사이드바처럼 콘텐츠 채팅창 바깥에 여백을 준다. 3분 초안.

## 1. 현 상태

* `ContentView.swift:369-372`: 바깥 카드가 `padding(12, 안쪽)→배경→radius 12→separator 외곽선`으로 content 컬럼에 딱 붙음 (바깥 여백 0).
* `sidebar` (`ContentView.swift:581-634`): 바깥 패딩 없음. 스크린샷 좌·하단 단차는 중앙 카드 모서리 vs 윈도우 배경 대비.
* 안쪽 3단 (메시지 768·입력·로그)은 T-091/093/096 범위라 건드리지 않음.

## 2. 단계 (T-098)

* 바깥 카드 뒤에 외부 여백 12 추가: `overlay(stroke)` 뒤 → `.padding(12)` (투명 갭, 윈도우 배경 노출).
* 안쪽 `.padding(12)` 유지. 768 cap·앵커 좌표계·추종 로직 무영향.
* 버전 0.7.59 + CHANGELOG + TODO 체크.

## 4. 바깥 12→8 조정 (T-098 후속)

* `ContentView.swift:373` 외부 `.padding(12)` → `.padding(8)`. 안쪽 12·배경·외곽선 유지.
* 효과: 카드가 디바이더·하단에 4pt씩 접근, 768열 +8pt. 인스펙터 `padding(8)` 톤과 통일.
* 버전 0.7.60에 포함.

## 5. 입력창 뼈대 통일 (T-097)

* 원인: 터미널은 배경+테두리가 바깥 VStack (`ChatBubbles.swift:577-580`)이라 768 꽉 참. 입력창은 배경+테두리가 안쪽 TextEditor (`ChatBubbles.swift:376-378`) + 바깥 `.padding(12)` (`:408`)라 24pt 좁음.
* 수정: 바깥 VStack(`:367-408`)에 배경+`cornerRadius 8`+`separator` 추가 (터미널과 동일). TextEditor는 투명화 (배경·clip·stroke 제거, `.padding(6)`·높이·단축키·플레이스홀더 유지). 컨트롤 줄(`:394-407`)은 이미 같은 VStack 안이라 자동 포함.
* 측정 유지: `InputWidthKey` 기준 동일 VStack, 미러 `containerWidth - 46` 그대로 (박스−바깥24−에디터12−여유10).
* 검증: 빌드 + 눈 확인 4종 (외곽선 일치·멀티라인·첨부행·플레이스홀더/비활성화). 순수 로직 변경 없어 unit 추가 없음.

## 6. 유저 버블 좌우 숨쉬기 (T-099, 어시스턴트는 그대로)

* 요청: 응답 버블은 현행 유지, 입력(유저) 버블만 좌우 여백 복원.
* 원인: T-096에서 유저 본문(`ChatBubbles.swift:246`) 좌우 패딩 제거 → 틴트 턱에 글자 밀착.
* 수정 1줄: `:246` `.padding(.vertical, 12)` → `.padding(12)`. 푸터(`:249-256`)는 버블 바깥 별도 줄이라 손대지 않음 (우측 기준 정렬 유지).
* 어시스턴트(`:280`·`:288`)·CSS(`markdown.css:15`) 그대로.
* 검증: 빌드 + 눈 확인 (유저 버블 좌우 숨쉬기·우측 정렬·다크/라이트). unit 추가 없음. 버전 0.7.61.

## 7. 터미널 탭 전환 고정 (T-100, 헤더 자리 유지 포함)

* 현상: 서버 로그↔시스템 전환 시 크기·위치가 바뀌어 보임.
* 원인: 바깥 144 고정(`ChatBubbles.swift:582`)이라 외곽은 그대로인데, 안쪽이 탭마다 다름 — 서버 `List` 풀필(`:527-549`) vs 시스템 3셀 intrinsic(`:552-575`, 제목+차트44+패딩 ≈ 76)이라 밑단 차이 + List 인셋 vs 셀 패딩 윗줄 차이. 헤더 우측 복사 3종도 서버 탭·로그 있음 조건(`:494`)이라 나타났다 사라짐.
* 수정: ① 탭 콘텐츠를 `Group` + `.frame(maxWidth: .infinity, maxHeight: .infinity)`로 동일 영역. ② 시스템 `HStack` + 셀(`SystemCellView`, 하단 전용이라 내부 수정)에 `maxHeight: .infinity` → 카드가 밑단까지 차서 List와 일치 (차트 44 자체는 유지). ③ 헤더 복사 3종을 조건 제거 대신 `HStack` 상시 + `opacity+disabled` 자리 유지 (X 위치·헤더 높이 고정).
* 검증: 빌드 + 눈 확인 (전환 시 외곽·헤더·밑단 무이동, 빈 로그·외부 데몬 안내도 동일 높이). unit 추가 없음. 버전 0.7.62.
