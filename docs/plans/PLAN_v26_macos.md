# PLAN v26 — 데몬/네이티브 분리 제어 + 입력창 경로 선택 (macOS)

## 1. 목표

데몬·네이티브 각각 실행/중지/다시 실행. 전송 경로는 입력창에서 매번 선택.
전역 엔진 토글은 폐기 (초기 route만 1회 승계).

## 2. 결정 (사용자 확정)

* 경로 선택: 입력창 피커, 매 전송 적용.
* 네이티브 중지 후 재전송: 자동 재준비 없음, 수동 실행 필요.
* 전역 토글: 폐기, 설정 화면은 안내 문구로 교체.

## 3. 변경

* T-185 네이티브 수명주기: `NativeEngine.State` 게시 (미초기화/준비 중/준비됨/실패).
  사이드바 엔진 행에 실행/중지/다시 실행 버튼 + 스피너 + 실패 코드.
  전송 시 자동 prepare 제거, 미준비면 차단+안내.
* T-186 경로 선택: `ChatStore.route` 소유, 입력창 segmented 피커.
  `canSend`를 선택 경로 기준으로. `EngineMode.current()` 전역 읽기를
  전 호출부에서 route 참조로 교체. 설정 토글 삭제.
* T-187 상태 표시: T-183 통합 상태 행을 선택 경로 기준으로 조정.
  툴바 ▶는 데몬 전담 명시.

## 4. 기존 동작 변경 2건

* 네이티브 미준비 전송: 자동 초기화 → 차단+안내.
* 설정 전역 토글 삭제.

## 5. 검증

* unit: 경로 분기·게이트·네이티브 상태 전이 회귀 + lint 신규 0.
* `test macos unit` + `build macos` 설치·눈확인 4종
  (데몬 3종·네이티브 3종·경로별 전송·미준비 차단 안내).
