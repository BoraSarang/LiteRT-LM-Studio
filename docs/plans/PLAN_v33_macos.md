# PLAN v33 — 스크롤뷰 교체 감지+자 불일치 진단 (macOS)

## 1. 목표

구 포인터 명령 사각지대 해소. 교체된 NSScrollView를 구 포인터로 읽고/쓰면 로그는
그럴듯하나 화면 무반응. T-207 1건.

## 2. 근거

* 0.7.141 로그: 전 보정 무음 + 백지 지속. 메시지 구조 전수 정상 (최대 줄 150자 미만).
* 진입 시작 문서가 이전 방 잔재 (2154→10405→14183→13710→8836 들쭉날쭉).

## 3. 변경 (T-207)

  인스턴스 변경 시에만 onFound + "스크롤뷰 교체 감지" 로그 (루프 방지).
* 진입 시작 시 `anchorMaxY=0` 리셋 (신선도 보장, stale 앵커 차단).

  "자 불일치" 로그 (동작 변경 없음, 증거용).
* 버전 0.7.142.
