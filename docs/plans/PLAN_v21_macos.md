# PLAN v21 — 본문 자간 복원 (macOS, T-174)

## 1. 목표

T-150 네이티브 전환 때 소실된 본문 자간을 복원. 좌우 패딩은 의도된 현행 유지.

## 2. 변경 (자간만)

1. `NativeMarkdown.tracking(for:)` 순수 헬퍼: `size × 0.015` (T-075 0.015em 복원, fontScale 연동).
2. 적용: `MarkdownView` 본문 5곳(제목·글머리·순서·인용·문단) + 표 셀 + `UserBubbleView` 질문 `Text`에 `.tracking()` (값은 1의 헬퍼로 통일).
3. 제외: 코드블록·인라인코드 run (T-075 "코드는 제외" 계승. 단 Text 단위 적용이라 인라인코드 조각에도 미세 적용됨 — 0.21pt 무시 수준).

## 3. 비범위

* 좌우 패딩 변경 없음 (의도된 설계 유지).
* 줄간격(lineSpacing) 변경 없음.

## 4. 검증

* unit 2건 추가 (14pt→0.21, 줌 연동) + lint 신규 0 + `test macos unit`.
* 빌드·설치·눈확인은 사용자 허락 후 (포커스 스틸 금지).
