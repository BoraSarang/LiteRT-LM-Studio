콜드스타트 첫 방 백지 해소. 핀 기본 true+앵커 0(보고 없음)=전부 스킵되는
"정상 착각" 상태. 버튼도 없어 탈출구 없음. T-212 1건.

## 2. 근거

* 0.7.146 로그: finder=없음 시작 → 수렴 종료 후 16초 무음 + 버튼 없음.

* 핀 기본 true가 버튼을 숨겨 수동 탈출까지 차단.
