# PLAN v89 — 웹 토글 명칭 정리 (macOS, T-309)

> 사용자 지적: 채팅 탭·도구 탭 둘 다 "검색"이라 구분 불가.

## 실태

* 채팅 탭 `웹 검색 사용` 1개가 `web_search`+`web_fetch` 둘 다 제어 (마스터).
* 도구 탭 `웹 검색`은 `web_search` 1개만 (개별).
* 같은 "검색" 표기가 다른 범위를 가리켜 혼란.

## 변경 (문자열만, 동작 불변)

1. `SettingsView.swift`: 채팅 탭 토글 → `웹 도구 사용` (help 유지).
2. `WebSearch.swift`: 마스터 OFF 메시지 2곳 → `웹 도구가 꺼져 있습니다. 설정에서 켜 주세요.`
3. `사용설명서.md`: `웹 검색 (내장 wigolo)` → `웹 도구 (내장 wigolo)`.
4. CHANGELOG 1줄.

## 검증

* unit + lint 신규 0 + build 1회. 눈확인: 설정 채팅 탭 표기.
