# PLAN_v107 — 엔진 초기화 실패 원인 표시 (T-336, macOS)

> 증상: 실행할 때마다 `E-MAC-ENG-0001`만 표시.
> 재현: 실모델 직접 초기화는 성공 (설정·MTP 포함) — 코드만으론 원인 불명 확인.
> 처방: 실패 원인을 보이게 + 흔한 원인(파일 없음) 선차단.

## 변경 (로직·플로우 불변)

* `prepare()` 파일 선확인: 없으면 `모델 파일 없음: 경로`로 즉시 실패.
* `lastErrorDetail` 신규: 사이드바 실패 행에 코드 대신 원인 2줄 표시
  (전체는 툴팁). `markInitFailed`·`boot` 실패 경로에서 설정.
* MTP 블록 `NativeEngine+Backends.resolveMTP`로 분리 (파일 길이 유지).

## 검증

* 신규 unit 1건 (없는 모델 즉시 실패+원인) + 287 회귀, lint 신규 0.
* 사용자에게 "다시 실행" 후 새 문구 확인 요청 (지속 시 디버그 패널 상세 줄).
