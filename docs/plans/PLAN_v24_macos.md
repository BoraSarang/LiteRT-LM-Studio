# PLAN v24 — Ollama식 상태 단일화 (macOS)

## 1. 목표

서버(데몬) 표시와 엔진(네이티브) 표시가 따로 놀아 "중지인데 대화됨" 혼란 해소.
Ollama식 단일 개념: 모델은 공용, 호출 경로(데몬/네이티브)만 다름.
사이드바에 "대화 가능" 1줄 상태를 보여준다.

## 2. 변경 (T-183)

* `UnifiedStatus.resolve(daemonRunning/unlinked/engineMode/preparedModelID)` 순수 헬퍼 (테스트 가능).
  - 데몬 실행 중 → "대화 가능 · 데몬" (네이티브도 준비됐으면 "데몬+네이티브").
  - 데몬 중지 + 네이티브 준비 → "대화 가능 · 네이티브(모델명)". ← 현재 사용자 케이스.
  - 미연결 외부 실행 → "외부 실행 중 (미연결)" 주황 유지 (T-179 계승).
  - 둘 다 없음 → "중지됨 · 시작 필요".
* 사이드바 환경 섹션: `서버` 행 → `상태` 행으로 교체 (점 색: 초록/주황/회색).
  `엔진` 행은 경로 상세로 유지 (CLI 데몬 / 네이티브·모델).
* 툴바 시작/중지 버튼 help에 네이티브 안내 추가 ("네이티브 대화 가능 중에도 CLI 데몬 제어").
* 버전 0.7.122.

## 3. 비범위

* 추론 경로 변경 없음 (모드 토글·prepare·serve 그대로).
* 하단 패널 게이트·데몬 폴러 로직 변경 없음.
* 메뉴바 표시 문구 변경 없음 (이번 묶음은 사이드바만).

## 4. 검증

* unit: UnifiedStatus 5케이스 추가 (기존 96 유지 목표).
* `test macos unit` + swiftlint 신규 0 + `build macos` 설치·눈확인.
* 눈확인: 네이티브 준비 상태에서 사이드바 `상태: 대화 가능` 표시.
