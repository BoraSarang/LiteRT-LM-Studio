# 사용설명서 — LiteRT-LM Studio (macOS)

> 앱 버전 0.7.152 기준. 버튼명·단축키는 앱 표시와 동일. 기능이 바뀌면 해당 장을 함께 고친다.

## 1. 시작하기

1. 첫 실행 시 랜딩에서 uv·litert-lm 설치 확인 후 "시작하기" (미설치면 명령 복사+재확인).
2. 사이드바 모델 목록에서 쓸 모델을 고른다.
2. ▶ 버튼(⌘R)으로 서버를 시작한다. 환경 섹션 `상태`가 초록 "대화 가능"으로 바뀌면 준비 완료.
3. 하단 입력창에 질문을 쓰고 Return으로 전송한다.

* 포트는 `127.0.0.1:9379` 고정, 모델 파일은 `~/.litert-lm/models` 참조.
* 전송 경로(서버 / 앱 내 엔진)는 입력창 피커에서 고른다. 앱 내 엔진은 사이드바 `엔진` 행 초기화 버튼으로 먼저 준비 (첫 1회 약 10초 이상).

## 2. 채팅

* **전송**: Return 또는 ⌘Return. 빈칸·공백만 있으면 전송 안 됨.
* **줄바꿈**: Shift+Return. 입력창은 2줄 시작·8줄 상한, 넘치면 내부 스크롤.
* **이미지 첨부**: 클립(📎) 버튼, PNG/JPEG만. 큰 그림은 자동으로 768px JPEG으로 축소. Vision 지원 모델에서만 답이 옴.
* **중단**: "중지" 버튼 또는 ⌘. (스트리밍·벤치마크 공통).
* **읽는 중 보호**: 위로 올려 읽는 동안 자동 추종이 멈춤. 맨 아래로 돌아오면 재개. 아래 화살표 원형 버튼으로 즉시 이동.
* **말풍선**: 질문(우측)에 마우스를 올리면 복사·수정해서 다시 요청. 응답(좌측)은 완료 후 복사·재시도. 완료 시 TTFT·tok/s·상대 시간 표시.
* **도구 호출**: 모델이 필요하면 스스로 도구를 씀 (🔧 칩에 이름·인자·상태 표시, 완료 시 결과 2줄).
  예: `지금 몇 시야?` `계산해줘 (1+2)*3` `최근 소식 검색해줘` `이 페이지 읽어줘 <URL>`.
  생각 과정이 있으면 회색 접기 블록으로 표시 (클릭 펼치기). 도구 지원 모델에서만 동작.
* **대화 목차**: 채팅 우측 중앙 바에 마우스를 올리면 질문 목록이 펼쳐짐. 클릭하면 해당 질문으로 이동 (1.5초 강조). 설정 채팅 탭에서 끄기 가능.
* **다시 요청**: 질문 아래 복사·연필 아이콘. 연필을 누르면 질문이 입력창에 채워지고 해당 내역 이후가 지워짐. 스트리밍 중엔 숨김.
* **후속 질문**: 응답이 끝나면 AI가 이어서 물을 만한 질문 3개를 우측에 제안 (클릭 즉시 전송). 생성 중엔 회색 자리 표시, 실패 시 기본 제안으로 대체. 설정 채팅 탭에서 끄기 가능.
* **채팅 글씨 크기**: 보기 메뉴 ⌘+ / ⌘- / ⌘0 (0.7~2.0배, 재실행 유지). 입력창·푸터는 고정.

## 3. 대화 관리 (사이드바 대화 섹션)

* **새 채팅**: "새 채팅" 버튼 또는 ⌘N. 누른다고 방이 바로 생기지 않고(드래프트), 첫 전송 때 생성됨.
* **선택·정렬**: 행 전체가 선택 영역. 정렬 메뉴(최근·이름·생성일).
* **핀·이름변경·삭제**: 행에 마우스 → ⋯ 메뉴. 이름변경은 입력창이 따로 뜸 (Enter 저장, ESC 취소). 삭제는 1회 확인.
* **복원**: 재실행하면 최근 사용한 방이 열림. 보기만 한 방도 기억됨.

## 4. 모델 관리 (사이드바 모델 섹션 + 모델 관리 창)

* 사이드바 목록 행: 표시 이름 + ID·목록 용량·실점유 용량. 클릭하면 채팅 모델로 선택.
* **모델 관리 창**: 사이드바 "모델 관리" 버튼 또는 ⌘K 팔레트 "모델 관리 열기".
  `[찾아보기 | 내 모델]` 탭. 찾아보기는 추천 모델 8종이 먼저 나오고,
  `전체 모델 보기`·검색창 입력으로 전체 목록 확장 (패밀리·정렬·더 보기).
  왼쪽에서 고르면 오른쪽에 상세(다운로드수·좋아요·뱃지·파일 선택·크기·README)와
  다운로드 버튼. 다운로드는 내 모델 탭 다운로드 중에 표시됨.
  하단엔 로컬 설치·스테이징 개수+용량+폴더 경로.
* **가져오기**: 추천 목록(Gemma·Qwen 대표) 또는 직접 입력(저장소·파일명·로컬ID·토큰).
  1 모델→2 파일→3 저장→4 진행 순서. 파일 목록은 저장소를 정하면 자동 조회,
  조회 실패 시 파일명 직접 입력. 시작 후엔 입력이 잠기고 닫기만 가능.
  창을 닫아도 다운로드는 계속되고, 다시 열면 진행·취소 가능.
  진행행: 파일명+퍼센트·용량·속도·경과·남은 시간, 바닥 바로 진행률.
  버튼: 받는 중 일시정지·취소·삭제, 멈춤은 이어받기, 취소·실패는 다시 받기.
  삭제는 확인 후 목록 제거 (미완성 파일도 함께 삭제). 취소는 완전 취소.
  받은 파일은 `~/.litert-lm-studio/staging` (숨김 폴더)에 계속 보관됨.
  앱을 껐다 켜면 받던 목록이 일시정지로 복원됨 (이어받기로 계속, 토큰은 다시 입력).
  기록 없는 미완성(`.part`)은 미완성 섹션에 표시, 출처를 알면 이어받기,
  모르면 다시 받기(찾아보기 검색 이동)·삭제 가능.
* **삭제·이름**: 모델 관리 창 내 모델 탭에서만 (사이드바 우클릭은 관리 창으로 이동).
  모델 삭제는 레지스트리만 제거 (받은 파일 유지, 다시 설치 가능).
  받은 파일까지 지우려면 확인문의 체크박스 사용. 파일 삭제는 디스크 파일만 지움
  (설치된 모델은 유지됨).
  표시 이름 바꾸기는 별칭(ID 불변), 실제 ID 변경은 레지스트리 rename.
* **파일로 설치**: 내 모델 헤더 `파일로 설치` → 로컬 `.litertlm` 선택 → 스테이징에 복사
  (원본 유지, 같은 이름 있으면 실패). 복사 후 다운로드 완료·미설치로 표시, 설치 버튼으로 등록.
* **설치**: `다운로드 완료·미설치` 행에서 "설치" → 레지스트리 등록 후 `설치됨`.
  스테이징 파일과 설치 모델을 둘 다 들고 있어 디스크를 2배 씀.
* **삭제·이름**: 설치 모델 우클릭 메뉴. 표시 이름 바꾸기는 별칭(ID 불변),
  실제 ID 변경은 레지스트리 rename (중복 ID면 E-MAC-STOR-0012). 모델 삭제 메뉴는
  내 모델 탭으로 이동 (사이드바에는 없음).

* 목록 행: 표시 이름 + ID·목록 용량·실점유 용량. 클릭하면 채팅 모델로 선택 (사이드바).
  사이드바 우클릭 메뉴: 채팅 선택·별칭·벤치마크·관리창에서 삭제.
  모델 삭제·가져오기·설치는 전역 권한(사용 안 함/매번 묻기/모두 허용) 적용.
  채팅 전송은 항상 허용 (권한과 무관). 실패하면 E-MAC-STOR-0006.
* **벤치마크**: 우클릭 "벤치마크 실행" 또는 사이드바 "벤치마크 열기".
  별도 창에서 모델·모드(앱 내 엔진/서버)를 고르고 "측정 시작".
  예상 소요가 먼저 표시되고(앱 내 엔진 약 1~3분, 서버 약 3~10분, 12B 서버는 타임아웃 가능),
  진행 중엔 4단계+경과 시간+로그가 표시됨. ⌘. 로 중단.
  결과는 막대 그래프+한국어 해설, "분석 시작"으로 측정한 경로의 개선 제안 리포트 확인 (복사 가능).
  앱 내 엔진 기록은 앱 내 엔진 초기화 후 분석 가능.
  기록은 자동 저장 (설정에서 10/50/100/제한없음 보관, 사이드바에 최근 3건).
* 행의 capability는 `describe` 실측: Thinking·Function Calling 지원 여부, Speculative 포함 여부, 모달리티(Text Vision Audio).

## 5. 실행 설정 (인스펙터)

바꾸면 주황 요약+적용·취소가 뜸. **적용은 서버 재시작을 동반** (앱 내 엔진은 다음 초기화 때 반영).

* **LLM 실행**: GPU (Metal) / CPU. CPU로 바꾸면 CPU 스레드 행이 나타남.
* **Vision 실행**: GPU / CPU.
* **Audio 실행**: 오디오 모달리티 모델을 고르면 나타남. CPU / GPU.
* **CPU 스레드**: 빈칸이면 자동. 1 이상 숫자.
* **캐시**: disk(컴파일 결과 저장, 재부팅해도 빠름) / memory / no(매번 재컴파일).
* **KV 토큰**: 입력+출력을 합친 전체 창. 빈칸이면 모델 기본. 크게 잡으면(예: 16384·32768) 긴 대화 가능, GPU 메모리 사용 증가.
* **MTP (Speculative Decoding)**: drafter 포함 모델에서 디코드 가속. 모델이 미포함이면 켤 수 없음.
  기본 끔 (발열·배터리). 켜면 벤치마크 창에 경고 표시. 앱 내 엔진은 모델 내장 drafter 유무로 자동 판정.
* **모델 Speculative·모달리티**: 현재 모델 실측 표시 (읽기 전용).
* **Thinking 기본값·예산**: thinking 지원 모델에서만 표시. serve 기본값 (대화마다 끄고 켜는 건 생성 설정).
* **고급**:
  * Metal residency (기본 켬): GPU 메모리에 모델 상주, 스와핑 방지. 앱 내 엔진 초기화 때 적용.
  * Visual 예산 (70/140/280/560/1120): 이미지당 시각 토큰 상한, Gemma4 전용. 기본 1120(상한).
  * 정밀도 (내장/fp16/fp32/int8/int16): 연산 정밀도 재지정. serve 경로만 유효.

## 6. 생성 설정 (인스펙터, 즉시 적용·재시작 없음)

* **Temperature** (기본 1.00, 0~1.5): 낮추면 단조·정확, 높이면 다양·창의적.
* **TopK** (기본 64): 후보 토큰 수. 1이면 탐욕 디코딩(항상 1순위).
* **TopP** (기본 0.95): 누적 확률 컷. 낮추면 안정, 높이면 다양.
* **Max 토큰**: 응답 길이 상한. 빈칸이면 무제한.
* **Seed**: 빈칸이면 랜덤. 숫자 고정 시 같은 질문에 같은 답 (재현용).
* **시스템 프롬프트**: 대화 성격 지시 (예: 간결하게 답해). 앱 내 엔진 모드에서만 전달, 서버 경로는 무시.
* **Thinking**: thinking 지원 모델에서만 켜짐 + 예산 (빈칸=무제한). 현 모델 미지원이면 비활성 + 사유 캡션.
* **Function Calling**: FunctionGemma 계열 필요. 현 모델 미지원이면 비활성.

## 7. 설정 일반 (설정… 메뉴)

* **외관**: 시스템 / 라이트 / 다크 강제. 마크다운·차트도 함께 바뀜.
* **언어**: 시스템 / 한국어 / English (기본 시스템). 앱이 그리는 문구는 재시작 없이 바로 바뀌고,
  권한 대화상자처럼 macOS가 그리는 문구는 다음 실행 때 반영됩니다.
* **Dock에 아이콘 보이기**: 끄면 메뉴바 상주만 (기본). 켜면 Dock에도 표시.
* **로그인 시 자동 실행**.
* **앱 종료 시 데몬도 함께 종료** (기본 켬). 끄면 앱을 닫아도 데몬이 남아 다음 실행 때 바로 씀. 터미널 데몬은 항상 유지.
* **대화 기록 전송**: 매 전송에 포함할 과거 범위 (제한 없음 / 10·20·40턴). 서버·앱 내 엔진 공통.
* **권한**: 사용 안 함 / 매번 묻기(기본) / 모두 허용. 채팅 전송·모델 삭제에 적용.
* **도구 탭**: 모델이 쓸 수 있는 기능 전수 (현재시각·사칙계산·웹 검색·페이지 가져오기·
  셸 실행·코드 저장·파일 읽기·시스템 정보·클립보드 읽기/쓰기·URL 열기·단축어 실행·
  일정 조회/추가·미리 알림 조회/추가·MCP 목록·MCP 호출). 각 행 토글로 개별 ON/OFF. 꺼진 도구는 모델에게 전달되지 않음.
  실행 여부는 위 권한이 정함 (매번 묻기=호출마다 확인 팝업).
* **시스템 도구 (T-270)**: 일정·미리 알림은 macOS 시스템 설정 > 개인정보 보호 및 보안에서
  캘린더·미리 알림 접근을 허용해야 동작 (거부 시 E-MAC-PERM-0016). 날짜는 "내일 오후 3시"처럼
  한국어 상대 표현으로 지정 (해석 실패 시 E-MAC-VALID-0017). `open_url`은 http·https만,
  `run_shortcut`은 도구 탭 **단축어 허용 목록**에 등록한 이름만 실행됩니다.
* **작업폴더**: 셸·파일 도구가 접근할 수 있는 폴더 (기본 `~/.litert-lm-studio/workspace`).
  밖은 차단됨. 셸에서 삭제·관리자 명령·파이프 실행·환경/서명/SSH 자산은 항상 거부.
* **웹 도구 (Exa API)**: 채팅 탭 토글로 사용 여부. 쓰려면 [dashboard.exa.ai](https://dashboard.exa.ai)에서
  발급한 API 키를 도구 탭 웹 섹션에 입력합니다. 키가 없으면 웹 도구가 모델에게 전달되지 않고,
  검색을 시도하면 설정 안내 문구가 반환됩니다. 웹 섹션에서 키 발급 링크·실검색 **테스트** 버튼을
  제공하며, 키는 이 Mac에만 저장됩니다.
* **MCP 탭**: 외부 MCP 서버 연결 (stdio 명령·SSE URL). 추가·삭제·켜짐·연결 테스트.
  모델은 `mcp_list_tools`로 목록 확인 후 `mcp_call`로 실행. 호출마다 권한 확인 팝업.
* **스킬 탭**: `~/.litert-lm-studio/skills/<이름>/SKILL.md` 작성 후 새로고침·토글.
  `폴더 추가`로 외부 스킬 루트를 등록할 수 있고, `가져오기`로 Claude(`~/.claude/skills`)·
  opencode(`~/.config/opencode/skills` 등)의 SKILL.md를 골라 복사할 수 있음.
  켜진 스킬이 시스템 프롬프트 앞에 들어감 (합계 8KB). 다음 전송부터 적용.

## 7-1. 앱 데이터 폴더

* 앱이 만드는 데이터는 `~/.litert-lm-studio/` 한 곳에 모임:
  `chats/`(대화 기록)·`mcp/`·`skills/`·`benchmarks/`·`engine-cache/`·`staging/`(받은 모델)·`workspace/`.
* 모델 자체는 `~/.litert-lm/models`(litert-lm CLI와 공유)를 그대로 참조.
* 첫 실행 시 기존 흩어진 데이터를 새 홈으로 자동 이사함 (소형 파일은 복사=원본 보관,
  받은 모델은 이동). 이사 로그는 디버그 패널 `[마이그레이션]`. 홈 변경은 설정 일반 탭에서
  경로를 보고 `studioHome` 값으로 재지정 가능 (재실행 반영).

## 8. 서버·앱 내 엔진 실행 제어

* **상태 행**: 환경 섹션 `상태`가 Ollama식 통합 표시. 초록 "대화 가능"=선택 경로 준비됨. 회색 "중지됨"=준비 안 됨 (경로별 안내 표시).
* **전송 경로**: 채팅 입력창 메뉴에서 매번 선택 (서버 / 앱 내 엔진). 설정에 전역 토글 없음.
* **채팅 모델**: 입력창 모델 메뉴에서 선택 (설치된 모델만, Gemma·Qwen 우선). 사이드바 선택과 동기.
* **데몬 시작/중지/다시 실행**: 툴바 ▶/■ (선택 경로를 따라감), ⌘R / ⌘.는 데몬 전담, 팔레트(⌘K), 메뉴바, 서버 메뉴.
* **앱 내 엔진 초기화/중지/다시 실행**: 사이드바 `엔진` 행 버튼. 중지는 메모리 반납. 중지 후 전송은 차단+안내 (자동 재준비 없음).
* **외부 데몬**: 터미널에서 먼저 띄운 서버면 "실행 중 (외부)"로 연결됨. 중지해도 터미널 프로세스는 안 죽고 연결만 끊김.
* **미연결 표시**: 연결을 끊은 외부 데몬이 살아있으면 주황 "외부 실행 중 (미연결)". ▶ 버튼으로 재연결.
* **인수해서 재시작**: 외부 데몬을 앱 소유로 바꾸고 싶을 때 확인 대화상자 후 교체.
* **로그**: ⌘J 하단 패널 [서버 로그] 탭. 외부 데몬 로그는 볼 수 없음 (안내+인수 버튼 표시). [시스템] 탭은 CPU/RAM/GPU 미니.

## 9. 시스템 현황·디버그·메뉴바·단축키

* **시스템 현황**: CPU(사용자 파랑+시스템 빨강)·RAM(App 노랑+Wired 빨강+압축 파랑)·GPU 추정치. 호버 팝오버, LIVE 1초 갱신.
* **디버그 패널** (⇧⌘D): 별도 창. 레벨 필터·검색(건수·이전/다음)·행 선택 복사·자동 스크롤·핀.
* **명령 팔레트** (⌘K): 새 채팅·서버 시작/중지·하단 패널·디버그 패널.
* **메뉴바**: 상태점 아이콘. 메인 창 열기·서버 시작/중지·하단 패널·디버그·설정·정보·종료.
* **정보 창**: 앱 메뉴 → 정보. 버전·제작자 표시 (사용 라이브러리 목록은 현재 비어 있음).
* **단축키 표**: ⌘N 새 채팅 · ⌘R 서버 시작/모델 새로고침 · ⌘. 중지/연결 끊기 · ⌘J 하단 패널 · ⌘K 팔레트 · ⌥⌘I 인스펙터 · ⇧⌘D 디버그 · ⌘+/-/0 글씨 크기 · ESC 대화상자 닫기.
